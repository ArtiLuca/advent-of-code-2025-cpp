# Advent of Code 2025 — C++ Solutions

This repository contains my personal solutions for
[Advent of Code 2025](https://adventofcode.com/2025).

The project is primarily a learning exercise. I am using the puzzles to practice:

- modern C++;
- problem decomposition;
- parsing structured input;
- algorithms and data structures;
- testing and debugging;
- analysing time and space complexity;
- organising small C++ programs with separate interfaces and implementations.

These are exploratory solutions rather than attempts to produce the shortest or
most competitive implementations. Some solutions may be revised as I discover
cleaner algorithms or improve my C++ design.

## Repository structure

Each completed day has its own directory:

```text
dayXX/
├── README.md          final cleaned explanation
├── original_notes.md  original write-up / first reasoning notes
├── main.cpp
├── dayXX.cpp
├── dayXX.h
└── input.txt          not included
```

## Status

I completed Days 1–9 of Advent of Code 2025 as a focused C++ and algorithms practice project.

After Day 9, the puzzles became significantly more complex, so I decided to pause this year here and continue practicing with another Advent of Code year. I may come back to the remaining 2025 puzzles in the future.
